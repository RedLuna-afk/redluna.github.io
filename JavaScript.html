JavaScript

Что такое JavaScript?

JavaScript — язык программирования, который используется для создания интерактивных и динамических веб-страниц. Если HTML отвечает за структуру документа, а CSS — за его внешний вид, то JavaScript позволяет странице реагировать на действия пользователя.

С помощью JavaScript можно обрабатывать нажатия кнопок, изменять содержимое страницы, выполнять вычисления, создавать анимации, проверять формы и взаимодействовать с сервером.

JavaScript выполняется непосредственно в браузере, поэтому многие действия могут происходить без полной перезагрузки страницы.

Простейший пример:

console.log("Hello, JavaScript!");

Подключение JavaScript

JavaScript можно добавить непосредственно в HTML-документ или подключить из отдельного файла. Для больших проектов обычно используется отдельный файл с расширением .js.

Внутренний JavaScript:

<script>console.log("Привет!");</script>

Внешний файл:

<script src="script.js"></script>

При подключении внешнего файла код JavaScript хранится отдельно от HTML-разметки. Это позволяет сделать проект более организованным.

Переменные

Переменные используются для хранения данных, которые программа может использовать во время выполнения. В современном JavaScript для объявления переменных используются ключевые слова let и const.

Ключевое слово Назначение
let Переменная, значение которой можно изменить
const Константа, которую нельзя переназначить
var Старый способ объявления переменных

Пример:

let age = 21;
const name = "Сергей";

Типы данных

JavaScript поддерживает различные типы данных. Они позволяют хранить числа, строки, логические значения и более сложные структуры.

Тип Описание Пример
String Текст "Hello"
Number Число 42
Boolean Логическое значение true / false
Array Массив значений [1, 2, 3]
Object Объект с набором свойств {name: "Alex"}
Null Отсутствие значения null

Пример:

let name = "Alex";
let age = 25;
let online = true;

Операторы

Операторы используются для выполнения различных действий над значениями. С их помощью можно выполнять математические операции, сравнивать значения и строить логические условия.

Оператор Назначение Пример
+ Сложение 5 + 2
- Вычитание 5 - 2
* Умножение 5 * 2
/ Деление 5 / 2
=== Строгое сравнение 5 === 5
&& Логическое И a && b
|| Логическое ИЛИ a || b

Условные конструкции

Условные конструкции позволяют программе выбирать различные действия в зависимости от определённого условия. Наиболее распространённой конструкцией является if...else. 

let age = 18;
if (age >= 18) {
    console.log("Доступ разрешён");
} else {
    console.log("Доступ запрещён");
}

Такие конструкции позволяют создавать разные сценарии поведения программы в зависимости от введённых данных или состояния элементов страницы.

Циклы

Циклы используются для многократного выполнения одного и того же участка программы. Они особенно полезны при работе с массивами и большими наборами данных.

Цикл for:

for (let i = 0; i < 5; i++) {
    console.log(i);
}

В результате цикл выполнит тело программы несколько раз, изменяя значение переменной счётчика.

Функции

Функция представляет собой отдельный блок кода, который можно вызвать в нужный момент. Функции позволяют не повторять одинаковый код и разбивать программу на логические части. 

function greet(name) {
    return "Привет, " + name;
}

console.log(greet("Сергей"));

Функция может принимать параметры и возвращать результат с помощью ключевого слова return.

Массивы

Массив используется для хранения нескольких значений в одной структуре. Каждый элемент массива имеет свой индекс, начиная с нуля. 

const browsers = [
    "Chrome",
    "Firefox",
    "Edge"
];

console.log(browsers[0]);

В данном примере обращение к элементу с индексом 0 вернёт первый элемент массива.

Объекты

Объекты позволяют объединять связанные данные и свойства в одну структуру. Они широко используются при разработке веб-приложений. 

const user = {
    name: "Alex",
    age: 21,
    online: true
};

console.log(user.name);

Свойства объекта можно получать и изменять во время выполнения программы.

DOM и взаимодействие со страницей

DOM (Document Object Model) представляет HTML-документ в виде структуры объектов. JavaScript может обращаться к этим объектам и изменять содержимое страницы.

Например, элемент можно найти по его идентификатору с помощью метода getElementById(). 

const title = document.getElementById("title");

title.textContent = "Новый заголовок";

Таким способом JavaScript может изменять текст, классы, атрибуты и другие свойства HTML-элементов.

События

События позволяют программе реагировать на действия пользователя. Например, можно обработать нажатие кнопки, движение мыши или ввод текста.

Пример обработки нажатия:

const button = document.getElementById("button");

button.addEventListener("click", function() {
    alert("Кнопка нажата!");
});

Обработчики событий являются одной из основных возможностей JavaScript при создании интерактивных веб-страниц.

Асинхронный JavaScript

JavaScript также позволяет выполнять операции, которые занимают некоторое время, не блокируя работу интерфейса. Это особенно важно при работе с сервером и сетевыми запросами.

Для работы с асинхронным кодом используются такие инструменты, как Promise, async и await. 

async function loadData() {
    const response = await fetch("data.json");
    const data = await response.json();
    console.log(data);
}

JavaScript и браузер

Браузер предоставляет JavaScript специальные возможности для взаимодействия с веб-страницей и окружающей средой. С помощью встроенных API можно работать с DOM, хранилищем данных, сетевыми запросами и другими возможностями браузера.

Возможность Назначение
DOM Работа с HTML-документом
Fetch API Выполнение сетевых запросов
Local Storage Хранение данных в браузере
Console Вывод сообщений и отладка

Частые ошибки

При изучении JavaScript начинающие разработчики часто сталкиваются с ошибками в синтаксисе и логике программы.

  1. Пропущена закрывающая скобка или кавычка.
  2. Используется переменная, которая ещё не объявлена.
  3. Неправильно указан идентификатор HTML-элемента.
  4. Событие привязано к несуществующему элементу.
  5. В условии допущена логическая ошибка.
  6. Ошибка возникает из-за неправильного типа данных.

Для поиска ошибок удобно использовать Console в DevTools. Браузер выводит туда сообщения об ошибках, предупреждения и результаты выполнения кода.

Итог

JavaScript является языком программирования, который позволяет сделать веб-страницы интерактивными. Он используется для обработки действий пользователя, изменения содержимого страницы, выполнения вычислений и взаимодействия с сервером.

Основу работы с JavaScript составляют переменные, типы данных, операторы, условия, циклы, функции, массивы и объекты.

В сочетании с HTML и CSS JavaScript позволяет создавать полноценные интерактивные веб-приложения.
