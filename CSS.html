CSS

Что такое CSS?

CSS (Cascading Style Sheets) — каскадные таблицы стилей, которые используются для оформления веб-страниц. Если HTML определяет структуру документа, то CSS отвечает за его внешний вид.

С помощью CSS можно изменять цвета, размеры, шрифты, отступы, положение элементов, фон, границы и многие другие характеристики страницы.

CSS позволяет отделить структуру документа от его оформления. Благодаря этому один и тот же HTML-документ можно оформить совершенно по-разному.

Простейший пример:

p {
    color: blue;
    font-size: 18px;
}

Способы подключения CSS

CSS можно подключить к HTML-документу несколькими способами. На практике чаще всего используется отдельный файл CSS, поскольку он позволяет хранить стили отдельно от HTML.

Способ Описание Пример
Внешний файл Стили находятся в отдельном файле style.css
Внутренние стили CSS находится внутри элемента <style> <style> ... </style>
Inline Стиль записывается непосредственно в элементе style="color: red"

Подключение внешнего файла:

<link
    rel="stylesheet"
    href="style.css"
>

Селекторы CSS

Селектор определяет, к каким HTML-элементам будут применены определённые стили. CSS предоставляет большое количество различных селекторов.

Селектор Назначение Пример
По тегу Выбирает элементы определённого типа p
По классу Выбирает элементы с определённым классом .menu
По идентификатору Выбирает элемент с определённым id #header
Универсальный Выбирает все элементы *

Пример:

.title {
    color: purple;
    font-size: 32px;
}

Цвета и фон

CSS позволяет задавать цвет текста, фона и других элементов. Цвет можно задавать несколькими способами: названием, шестнадцатеричным кодом, RGB, RGBA и другими форматами.

Пример цвета текста:

h1 {
    color: #704A8E;
}

Для фона можно использовать не только обычный цвет, но и изображения, градиенты и другие эффекты.

Градиент:

.page {
    background:linear-gradient(90deg,#FBC2EB,#A6C1EE);
}

Размеры и отступы

CSS позволяет управлять размерами элементов и расстояниями между ними. Для этого используются свойства width, height, margin и padding.

Свойство Назначение
width Ширина элемента
height Высота элемента
margin Внешний отступ
padding Внутренний отступ 
.card {
    width: 300px;
    padding: 20px;
    margin: 30px;
}

Шрифты и текст

С помощью CSS можно изменять внешний вид текста: выбирать шрифт, размер, начертание, межстрочное расстояние, выравнивание и цвет. 

p {
    font-family:Arial, sans-serif;
    font-size: 18px;
    line-height: 1.6;
    text-align: justify;
}

Правильный выбор шрифта и размера текста важен для удобства чтения страницы. Также необходимо учитывать контраст между текстом и фоном.

Границы и скругления

CSS позволяет создавать границы вокруг элементов. Их цвет, толщину и стиль можно изменять с помощью свойства border.

Для создания скруглённых углов используется свойство border-radius. 

.card {
    border:2px solid #704A8E;
    border-radius:15px;
}

Такие свойства часто используются при создании карточек, кнопок, панелей и других элементов интерфейса.

Flexbox

Flexbox — это механизм CSS для удобного расположения элементов внутри контейнера. Он позволяет управлять направлением, выравниванием и расстояниями между элементами.

Для включения Flexbox используется свойство display: flex. 

.menu {
    display: flex;
    justify-content:space-between;
    align-items:center;
}

Flexbox особенно удобен для создания навигационных меню, рядов карточек и различных элементов интерфейса.

CSS Grid

CSS Grid предназначен для создания двумерных сеток. В отличие от Flexbox, который в основном работает с одним направлением, Grid позволяет одновременно управлять строками и столбцами. 

.container {
    display: grid;
    grid-template-columns:repeat(3, 1fr);
    gap: 20px;
}

Grid удобно использовать для построения сложных макетов страниц, галерей и сеток карточек.

Адаптивная вёрстка

Адаптивная вёрстка позволяет странице корректно отображаться на различных устройствах: компьютерах, планшетах и смартфонах.

Для изменения оформления в зависимости от ширины экрана используются медиазапросы. 

@media (max-width: 768px) {
    .menu {
        flex-direction:column;
    }
}

Например, горизонтальное меню на большом экране можно превратить в вертикальное меню на смартфоне.

Позиционирование элементов

CSS предоставляет несколько способов позиционирования элементов. Свойство position позволяет определить, каким образом элемент будет располагаться относительно документа или другого элемента.

Значение Назначение
static Обычное положение элемента
relative Позиционирование относительно исходного места
absolute Позиционирование относительно ближайшего контейнера
fixed Фиксация относительно окна браузера
sticky Элемент может фиксироваться при прокрутке

Псевдоклассы

Псевдоклассы позволяют применять стили к элементам в зависимости от их состояния.

Например, псевдокласс :hover позволяет изменить оформление элемента, когда пользователь наводит на него курсор. 

button:hover {
    transform:scale(1.05);
    background:#704A8E;
}

Псевдоклассы часто используются для создания интерактивных кнопок, ссылок и элементов меню.

CSS и UIkit

CSS-фреймворки позволяют использовать готовые классы и компоненты для создания интерфейса. В данном проекте используется UIkit.

Например, UIkit предоставляет готовые классы для создания навигации, сеток, кнопок, таблиц и других элементов. 

<buttonclass="uk-button uk-button-primary">
    Кнопка
</button>

При этом собственный CSS можно использовать вместе с UIkit для изменения оформления компонентов под дизайн конкретного проекта.

Частые ошибки в CSS

При работе с CSS разработчики часто сталкиваются с проблемами, связанными с неправильными селекторами, наследованием и расположением элементов.

  1. Неправильно написан селектор.
  2. Класс в HTML не совпадает с классом в CSS.
  3. Свойство переопределяется другим правилом.
  4. Используется слишком высокая специфичность.
  5. Элемент выходит за пределы контейнера.
  6. Отсутствуют медиазапросы для мобильных устройств.

Итог

CSS является основной технологией для оформления HTML-документов. С его помощью можно управлять внешним видом практически каждого элемента веб-страницы.

Знание селекторов, размеров, отступов, Flexbox, Grid, позиционирования и медиазапросов позволяет создавать современные и адаптивные интерфейсы.

HTML отвечает за структуру, CSS — за внешний вид, а JavaScript — за поведение и интерактивность страницы. Совместное использование этих технологий является основой современной веб-разработки.
